# Italiano Flow

Una PWA mobile-first per allenare il lessico italiano B1–C1 nel contesto, con particolare attenzione al lavoro, al business e alla tecnologia.

## Versione online

https://chenpihuamei.github.io/italiano-flow/

## Funzioni incluse

- 50 parole e 150 esempi contestuali.
- Sei tipi di esercizi: significato, parole simili, contesto, grammatica, senso e collocazioni.
- Lettura B2, carte di ripasso e importazione locale di sottotitoli SRT/VTT.
- Progressi salvati soltanto nel browser tramite localStorage.
- PWA installabile e shell disponibile offline dopo il primo caricamento riuscito.

## Privacy

Questa repository pubblica non contiene il profilo personale del proprietario del progetto. Non esiste un account o un database: ogni dispositivo conserva un progresso indipendente. I sottotitoli importati restano nel browser.

## Pubblicazione

Il workflow `.github/workflows/deploy-pages.yml` pubblica automaticamente il sito con GitHub Pages a ogni push su `main`.
